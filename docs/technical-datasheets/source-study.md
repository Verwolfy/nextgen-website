# Étude des 3 archives de référence

108 PDF français / 190 pages ; 171 PDF anglais / 241 pages ; 86 PDF arabes / 186 pages, soit 365 PDF / 617 pages. 130 noms distincts normalisés, 66 présents dans 3 langues.

Les rubriques types couvrent description, utilisations, avantages, performances, préparation/application, dosage/consommation, stockage et sécurité. Les trois langues ne sont pas toujours concordantes.

Écarts observés : GRANIPAN F10 — 25 kg en français/anglais contre 40 kg en arabe ; MEDAPLAST SP 40 — conditionnements différents selon langue ; MEDAPOXY PRIMER — certaines unités arabes incorrectes ; GRANICOL — texte d'un autre produit dans la rubrique usages FR.

Les anciens PDF arabes présentent également des problèmes possibles d'ordre de caractères/chiffres à l'extraction. Ne jamais recopier ces données dans une FT NextGen.

Une seule base de valeurs signées doit alimenter les trois éditions, avec contrôle numérique et linguistique. Ne pas importer les PDF tiers dans GitHub.
